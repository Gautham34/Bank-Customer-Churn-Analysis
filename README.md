# Bank-Customer-Churn-Analysis

**Overview:**
This project analyzes bank customer churn to identify key factors driving customer exits.
The analysis was done using Python (EDA + Feature Engineering) and Power BI.

**Dataset:** Bank Turnover Dataset
https://www.kaggle.com/datasets/barelydedicated/bank-customer-churn-modeling/data

**Key Metrics**
Total Customers: 10,000
Churned Customers: 2,037
Churn Rate: 20.37%

**Main Insights**
1) Younger customers (18–35) churn more.

2) Germany has the highest churn rate.

3) New and inactive customers are more likely to leave.

4) Single-product holders churn the most.

5) Low-balance and medium-salary segments show higher churn.


**Tools Used:**

Python: pandas, matplotlib, seaborn
Power BI: DAX, Power Query, Data Modelling, Dashboard creation and Visualization.
